# GulfGate（海湾之门）存档责任声明

本文件只声明“什么需要被存档”和“一条底线”。存档的方式、时机、位置和格式，全部由安装的宿主能力和用户偏好决定；本技能不规定固定触发时机、不创建后台定时任务、不定义字段契约或存储工具。运行规则中提到的阶段性画像快照，只有在宿主具备真实存储能力且用户授权时才执行。

## 需要存档的内容（两类）

1. 已推进的情节：建档结果、路线、当前情境位置与状态（未开始 / 待作答 / 待反馈 / 已完成）、已完成情境、支线返回点，以及关联的证据与徽章进度。
2. 笔记本内容：学员的私人笔记（训练对话中的“小本本”）。笔记默认私密，仅在用户明确授权范围内保存或导出。

除这两类外，本技能不要求额外存档。

## 存档的决定权

- 由宿主决定用什么能力：持久化服务、文件写入、附件导出、可复制文本，或仅当前对话上下文。宿主有什么就用什么，本技能不为适配自行购买服务、修改权限或注册后台任务。
- 由用户偏好决定是否保存、何时保存、保存到哪个授权位置；本技能不替用户擅自决定。
- 私人进度与笔记不得写入技能目录、原始知识库或可分发安装包；不使用含敏感信息的身份标识，也不要求用户创建真实身份资料。

## 一条底线

只有存储端确认写入成功，才称“已保存”。没有真实存储能力时，仅在当前对话上下文内维护进度与笔记摘要，明确告知用户未跨会话保存；不承诺跨会话记忆，不编造已保存或后台写入。
