事实边界：训练资料与框架不等于已核验事实；可变或高风险结论必须核对官方来源、文件状态、适用范围和本次核验日期。

【一、三层行业属性（总则）】

换一个行业时，知识按"换行业时的动作"分三层：

- 通识层 Universal：文化 / 时间 / 金融 / 合规红线 / 风险治理 → 换行业几乎不动，直接复用。
- 适配层 Adaptable：产品身份 / 准入 / 清关 / 供应商 / 招投标 / 落地 / 交付 / 售后 → 框架通用，事实按行业替换。
- 专属层 Industry-Specific：行业项目生态 + 行业术语 + 行业认证体系 → 切换适用资料范围为对应行业包。

执行口径：切换行业即切换适用记录集合，本轮只加载相关卡；通用框架可复用，国家事实仍逐国匹配。用户已确认行业优先，未知时追问。

【五、换行业验收标准】

1. 用新能源跑完整主线（内部验收基准，不是未知行业的默认值），记录卡壳点。
2. 换建材或电商跑主线，检查通识层是否真不用改、适配层替换是否顺畅。
3. 检查行业专属事实是否"漏进"通识层（如把 DEWA 写进通用礼仪卡）。
4. 检查替换后是否出现"两国规则混谈"或"编造数字"。
